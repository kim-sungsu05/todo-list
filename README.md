# Todo List

간단한 Todo List 웹 애플리케이션을 개발하며  
프론트엔드와 백엔드의 연결 및 웹의 동작 원리를 학습하기 위한 프로젝트입니다.

## 🛠️ Tech Stack

- HTML
- CSS
- JavaScript
- Node.js
- Express
- MongoDB
- Mongoose
